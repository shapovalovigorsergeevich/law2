# Сайт Шаповалова Игоря Сергеевича

Коммерческий адаптивный сайт на чистом HTML/CSS/JS.

## Перед публикацией заменить
- номер телефона;
- e-mail;
- город и адрес;
- фактические сведения об образовании и стаже;
- только подтверждённые цифры, отзывы и результаты;
- юридические документы сайта;
- endpoint формы/CRM вместо демонстрационного mailto;
- карту и реквизиты.

## Запуск
Откройте `index.html` в браузере либо разместите папку на любом статическом хостинге.

## Структура
index.html — главная;
privacy.html — шаблон политики;
assets/style.css — стили;
assets/script.js — интерактив;
assets/igor-shapovalov.jpg — исходный портрет.
